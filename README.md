# 까치 (Kkachi)

**까치 (Kkachi)**는 여러 개의 **IMAP / POP3** 이메일 계정을 순차적으로 모니터링하고, 새 메일이 도착하면 바탕화면의 **3D 까치 위젯**과 알림 팝업으로 알려주는 한국어 중심의 데스크톱 이메일 클라이언트입니다.

---

## 주요 기능

- **다중 계정 순차 모니터링 (IMAP / POP3)**
  - Gmail, Naver, Daum/Kakao, Outlook, iCloud, Yahoo 및 사설/회사 메일 서버 프리셋 지원
  - 서버 부하 없이 계정을 차례대로 확인하며, IMAP `uidNext` 고속 조회로 불필요한 재다운로드를 방지
  - OS 키체인/자격 증명 관리자(`Electron safeStorage`) 기반 비밀번호 암호화 저장
- **바탕화면 3D 까치 위젯**
  - 마우스 커서 위치를 따라 시선·고개가 움직이는 배경 없는 투명 데스크톱 위젯
  - 읽지 않은 새 메일이 있으면 편지 봉투를 물고 알려주며, 장시간 대기 시 꾸벅 조는 모션 및 상태 알림 표시
  - 위젯 우클릭/클릭 메뉴(받은편지함 열기, 모두 읽음 처리, 지금 메일 확인, 종료), 더블클릭으로 메인 창 열기, 드래그로 화면 어디든 이동
- **원문 · 한국어 번역 탭 보기**
  - 외국어 메일 수신 시 제목을 자동 번역해 알림으로 표시
  - 메일 본문은 HTML 레이아웃과 서식을 그대로 유지한 채 텍스트만 한국어로 번역해 원문/번역본을 탭으로 전환
- **간편한 읽기 · 답장 · 내보내기**
  - 메일 선택 시 내용 영역이 부드럽게 펼쳐지며 상단에서 바로 **답장(SMTP)**, **읽음/안 읽음 처리**, **인쇄**, **PDF 저장** 가능

## 다운로드 및 설치

[Releases 페이지](https://github.com/creatorjosephkr/kkachi/releases)에서 운영체제에 맞는 설치 파일을 다운로드하세요.

### Windows (64-bit)
- **설치형**: `Kkachi-<버전>-Windows-x64.exe` 실행 후 안내에 따라 설치
- **포터블 (무설치)**: `Kkachi-<버전>-Windows-x64-Portable.exe` 다운로드 후 바로 실행
- *Windows Defender SmartScreen 경고가 뜨면 `추가 정보 → 실행`을 눌러 주세요 (개인 서명 없는 공개 빌드).*

### macOS
- **Apple Silicon (M1/M2/M3/M4)**: `Kkachi-<버전>-macOS-arm64.dmg`
- **Intel Mac**: `Kkachi-<버전>-macOS-x64.dmg`
- `.dmg` 파일을 열고 **Kkachi.app**을 `응용 프로그램(Applications)` 폴더로 드래그합니다.
- 공증되지 않은 앱으로 *"손상되었기 때문에 열 수 없습니다"* 또는 확인 경고가 표시될 경우, 터미널에서 아래 명령어를 한 번 실행해 주세요:
  ```bash
  xattr -cr /Applications/Kkachi.app
  ```

## 기본 사용 방법

### 1. 이메일 계정 추가
1. 까치 위젯을 **더블클릭**하거나 클릭 후 **이메일함 열기**를 선택합니다.
2. 좌측 하단 **+ 계정 추가** 버튼을 클릭합니다.
3. 메일 서비스 프리셋(`Gmail`, `Naver`, `Daum / Kakao` 등)과 프로토콜(`IMAP` 권장 또는 `POP3`)을 선택하고, 이메일 주소와 비밀번호를 입력합니다.
   - **Gmail / Naver / Yahoo 등 2단계 인증 계정**은 일반 비밀번호 대신 각 서비스 보안 설정에서 발급한 **앱 비밀번호**를 입력해야 합니다.
   - **Gmail POP3** 사용 시 Gmail 웹 `설정 → 전달 및 POP/IMAP`에서 POP 다운로드를 활성화해야 합니다.
4. **연결 테스트**로 정상 접속을 확인한 뒤 **저장**합니다.

### 2. 바탕화면 까치 위젯 조작
- **클릭**: 빠른 메뉴 열기 (받은편지함 열기, 모두 읽음 처리, 지금 메일 확인, 종료)
- **더블클릭**: 메인 이메일함 창 바로 열기
- **드래그**: 바탕화면 원하는 위치로 이동 (화면 좌/우 영역에 따라 바라보는 방향 자동 전환)

### 3. 메일 읽기, 번역, 인쇄 / PDF 저장
- 목록에서 메일을 클릭하면 오른쪽에 메일 내용 창이 펼쳐집니다.
- 한국어가 아닌 메일은 **원문** / **한국어 번역** 탭을 눌러 서식 그대로 번역해 볼 수 있습니다.
- 상단 버튼으로 **인쇄**, **PDF 저장**, **답장**, **읽음/안 읽음 전환**, **삭제**를 바로 수행할 수 있습니다.
- 좌측 상단 톱니바퀴(환경설정)에서 확인 주기(최소 15초), 알림음, 자동 번역 엔진(Google 무료 / DeepL / OpenAI), 테마, 까치 초기 위치를 바꿀 수 있습니다.

## 로컬 개발 및 직접 빌드

Node.js 20+ 환경에서 실행합니다.

```bash
# 의존성 설치
npm install

# 개발 모드 실행
npm run dev

# 타입 체크 & 단위 테스트
npm run typecheck
npm test

# 프로덕션 번들 빌드
npm run build

# macOS 패키징 (DMG / ZIP)
npm run dist:mac

# Windows 패키징 (x64 NSIS / Portable)
npm run dist:win
```
